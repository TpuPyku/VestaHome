Проверки на ГУ — тринадцатый лист

Составлено 2026-10-24 по исправлениям после проверки 2026-10-24-2: загрузчик, порт для навигаторов, касания, радио, камера, USB-модем, OBD. Двенадцатый лист в остальном в силе (пункты, отмеченные там «ок», не повторяются). ☐ — «сделано», «Заметки» — что увидели. Журналы включены, SD-карта вставлена.

1. Установка загрузчика (Tests\SDMemory\VestaHomeInstall)

№ДействиеЧто должно бытьЗаметки
1Установщик: отметить VestaHome (и proxy, как было) → «Установить».Нет отказа «уже наш proxy»; итог «Заряжено на следующую загрузку: поставит загрузчик VestaHome…» (без proxy).
2Перезагрузить ГУ (обычная перезагрузка), SD не вынимать.Пройдёт наш SwDnl, затем ещё перезагрузка; после неё сам запускается VestaHome.
3Установщик → «Статус».Загрузчик VestaHome стоит; G3NavHMI.exe — 12 288 Б.
4Ещё 2 раза: перезагрузка удержанием крутилки и выключение зажигания.Каждый раз VestaHome; в «Диспетчере задач» нет G3NavHMI_orig.exe. Есть VestaLogs\VestaStub.log.

2. Порт для навигаторов и Навител

№ДействиеЧто должно бытьЗаметки
5«Настройки → Автомобиль → Порт для навигаторов»: COM7, включить.«только NMEA · работает». В журнале «порт NMEA: COM7 загружен, …» — записать, каким способом (своя группа / группа 3 / в device.exe).
6Навител напрямую (не через vestanavi.mscr).Видит COM7, есть фикс.
7Поработать 10 минут с картой и музыкой.ГУ не зависает и не перезагружается (порт мог загрузиться в системный процесс).

3. Касания и радио

№ДействиеЧто должно бытьЗаметки
8Радио: нажимать пресеты по одному, с нажимом, 10 раз.Каждый раз включается пресет, страница не листается.
9Радио: листать свайпом FM1 → FM2 → … → СВ, затем обратно.Листается; на СВ дальше вправо и на FM1 дальше влево — не листается (без круга); с СВ обратно на УКВ / FM — СВ выключается.
10Главная, программы, файлы, фото: тапы и свайпы.Тап срабатывает с первого раза; свайп — с заметного движения вбок; список фото/файлов листается.
11Радио → Список → «Автопоиск», затем «В пресеты» два раза.Пишет «Пишу N из M», в конце «записано N из M»; пресеты FM1–FM3 — найденные станции.

4. Камера

№ДействиеЧто должно бытьЗаметки
12«Автомобиль → Камера — Показать», нажать на экран.Окно закрывается.
13«Показать» и не трогать.Закрывается само через 20 с.
14Задний ход, затем выключить его.Камера с разметкой, после — экран, где были.

5. USB-модем (Huawei, без SIM)

№ДействиеЧто должно бытьЗаметки
15«О системе → Диагностика → USB-модем (проба)».Кнопка подсвечена: «USB-модем: вставьте модем».
16Вставить модем, подождать 15 с; вынуть.ГУ не зависает. В VestaLogs\VestaModem.log: «размеры USBD», переключение, затем 12D1:1506 и ответы на AT / ATI.

6. OBD

№ДействиеЧто должно бытьЗаметки
17Bluetooth телефона выключен. «Настройки → Bluetooth → OBD-адаптер (проверка)» → «Найти» → адаптер → «Сопрячь» (PIN 1234, если нет — 0000).Сопряжено; если нет — код ошибки с экрана.
18«Подключить».Подключено, идут значения; если нет — время и код с экрана.
