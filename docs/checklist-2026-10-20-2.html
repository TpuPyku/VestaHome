Проверки на ГУ — восьмой лист

Составлено 2026-10-20 по журналам MAIN\HU_logs\2026-10-20-2. ☐ — «сделано», «Заметки» — что увидели. Нужны SD-карта и Bluetooth-телефон; для п. 8 — Note13.

1. Установка

№ДействиеЧто должно бытьЗаметки
1VestaHomeInstall: «1. VESTAHOME», затем «2» (новый proxy MCU и proxy Bluetooth), перезагрузка. Файл \SDMMC\SPIPower.on оставить.«СТАТУС»: proxy MCU и Bluetooth — «стоит (текущий)».
2LaunchInstall — новый VestaLaunch.Ставится, «Навигация» открывает лаунчер.

2. Один источник звука

№ДействиеЧто должно бытьЗаметки
3Играет радио. Медиа → Музыка → трек.Радио замолкает, играет трек (MCU переключился на «медиа»). В журнале «источник: медиа (было 0)». Если вместе с треком заиграла музыка оболочки — записать.
4Играет трек. Открыть «Радио» (или тап по пресету в виджете).Трек на паузе, играет радио.
5Играет BT-музыка с телефона. Включить интернет-радио, затем видео.BT на паузе; радио (интернет) играет; видео ставит его на паузу. Двух звуков сразу нет.
6Играет трек. Кнопка MODE на панели.Трек на паузе (журнал «источник: радио — наши плееры на паузу»).
7«Медиа → Bluetooth» → ▶, когда играл трек.Трек на паузе, играет телефон.

3. Радио

№ДействиеЧто должно бытьЗаметки
8Сразу после включения ГУ открыть «Радио».Частота и пресеты за 1–2 с (VestaHome будит тюнер, как оболочка при старте). В журнале «радио: тюнер ответил через N с» — записать N.
9Кнопка страниц по кругу: FM1 → FM2 → FM3 → УКВ → СВ → FM1 (СВ должно быть включено в «Настройки → Радио»).На СВ — частоты 522…1620 (кГц), свои 8 пресетов; на УКВ не зависает. Не переключилось — страница возвращается на настоящий диапазон и надпись «диапазон не переключился».
10Удерживать пресет (сохранить станцию).Подпись на кнопке меняется сразу.
11Виджет «Радио» на главной, когда играет СВ.«РАДИО · СВ», частота в кГц.

4. Списки файлов и галерея

№ДействиеЧто должно бытьЗаметки
12Медиа → Музыка → список; Видео; Фото; «Приложения» → изменить → выбор программы.Везде одинаково: свайп листает страницы, точки внизу; стрелок нет.
13Фото: свайп по плиткам.Едут только плитки; вкладки медиа сверху стоят.

5. Экран, телефон, звук

№ДействиеЧто должно бытьЗаметки
14«Настройки → Экран».Пункта «Яркость» нет.
15«Телефон»: удерживать «0».Набирается «+».
16«Настройки → Звук»: низкие +6, баланс влево.На слух меняется. В SPIPower.log строки «VH CALL SPApi_SendRadioAudioHMLData…» и ответ MCU 0x3102.

6. Bluetooth

№ДействиеЧто должно бытьЗаметки
17«Настройки → Bluetooth → Сопряжённые».Полный список (до 16, по 7 на страницу, точки внизу), подключённый — оранжевым.
18«УДАЛИТЬ» у ненужного устройства, «ТОЧНО?».Устройство пропало из списка (и из списка оболочки).

7. Свои виджеты и VestaLaunch

№ДействиеЧто должно бытьЗаметки
19Тап по «Пробкам».OSMapsCE открывается и остаётся на экране.
20Тап по «Навигации» (путь в navi.ini неверный, CityGuide есть в «Приложениях»).Запускается CityGuide (из «Приложений»). Если его там нет — строка «нет CityGuideCE.exe: добавьте в «Приложения»».

№ДействиеЧто должно бытьЗаметки
