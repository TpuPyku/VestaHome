Проверки на ГУ — двенадцатый лист

Составлено 2026-10-24 по исправлениям после проверки 24 октября (загрузка, кнопка «назад», свайпы, плеер, фото, камера), выбору порта для навигаторов, камерам Москвы, Wi-Fi и OBD. Одиннадцатый лист остаётся в силе. ☐ — «сделано», «Заметки» — что увидели. Журналы — «Диагностика → Журналы» включены, SD-карта вставлена.

1. Установщик (Tests\SDMemory\VestaHomeInstall)

№ДействиеЧто должно бытьЗаметки
1Запустить установщик.Панель задач WinCE скрыта, нижние кнопки видны целиком; выбранные пункты — оранжевые с галочкой.
2«VestaHome + загрузчик» → «УСТАНОВИТЬ / ОБНОВИТЬ»; отчёт длинный — потянуть пальцем.Отчёт прокручивается, справа полоска; после выхода панель задач вернулась. «О системе»: версия 0.6.261024.

2. Загрузка ГУ

№ДействиеЧто должно бытьЗаметки
3Выключить зажигание, дождаться сна, включить. Повторить 3 раза.Каждый раз запускается VestaHome, не штатная оболочка. В «Диспетчере задач» нет G3NavHMI_orig.exe.
4Открыть VestaLogs\VestaStub.log.Записи с самого начала загрузки (сначала в памяти, потом перенесены на карту): «ждём SD… / VestaHome запущен». Если запустилась штатная — записать, что в журнале перед этим.
5После загрузки VestaHome: переключить источник, включить задний ход, открыть OSMapsCE.Нет «спора» за источник; камера заднего хода — поверх OSMapsCE.

3. Кнопка «назад» и вложенные экраны

№ДействиеЧто должно бытьЗаметки
6Пройти вложенные экраны: настройки (Wi-Fi, Bluetooth, камеры, тема), Диагностика, Данные MCU, Поток GPS/CAN, Память и диски, Диспетчер задач, файлы.«Назад» — стрелка возврата слева внизу; нижней панели разделов там нет; кнопка не накрывает содержимое.
7Окно поверх экрана (например, подтверждение, ввод PIN).Своей кнопки «назад» у окна нет, окно не перекрыто.
8Диагностика; Данные MCU → «Запись», «Метка».Под кнопками нет пояснений, «Журналы» выше; кнопки записи — в нижней полосе справа от «назад», строка записи видна.
9Клавиатура (ввод пароля Wi-Fi).Здесь «назад» по-прежнему слева вверху, клавиши не перекрыты.

4. Свайпы, плеер, фото, файлы

№ДействиеЧто должно бытьЗаметки
10Главная: листать страницы свайпом, коротким и длинным, с нажимом.Страница перелистывается с первого раза; тап не принимается за свайп и наоборот.
11Музыка: короткий файл (несколько секунд) — пауза; «Играть всё».Пауза срабатывает, следующий трек сам не включается; «Играть всё» не налезает на список.
12Фото: открыть снимок, кнопка «во весь экран», тап.Снимок на весь экран без рамок; тап — обратно.
13«Тема → Своя картинка» — выбор файла.Миниатюры; мелкие файлы (значки) не показаны.
14Текстовые файлы (редактор своих виджетов): зайти в папку.Сверху строка пути, «‹» — уровень выше.
15Медиа → Bluetooth: кнопка воспроизведения.Такая же, как у музыки; управляет телефоном.
16Главная: виджеты, свечение, анимация нижней панели.Виджеты светлее, свечение справа сверху заметнее; панель переключается быстрее прежнего.

5. Камера заднего хода

№ДействиеЧто должно бытьЗаметки
17Задний ход (VestaHome без штатной оболочки).Своя камера с разметкой; после выключения заднего — возврат на экран, где были.
18«Автомобиль → Камера — Показать» без заднего хода.Картинка, если камера питается, иначе «Нет сигнала камеры…»; тап закрывает.

6. Порт для навигаторов и Навител

№ДействиеЧто должно бытьЗаметки
19«Настройки → Автомобиль → Порт для навигаторов»: стрелками выбрать COM7, включить.Подпись «только NMEA · работает»; в журнале «порт NMEA: COM7 загружен».
20Запустить Навител напрямую (не через vestanavi.mscr — тот запускает GpsGate).Автопоиск находит COM7, есть фикс, скорость совпадает с приборкой.
21Закрыть Навител; в VestaHome сменить порт на COM6 и обратно на COM7.Каждый раз «работает»; в журнале выгружен → загружен под новым номером, без ошибки.

7. Камеры скорости

№ДействиеЧто должно бытьЗаметки
22«Скачать базу камер»: регионы — «Москва» и «Московская» (плюс свой), скачать.Качаются по одному («1 из 3»…), итог — число камер; для Москвы с областью ≈ 7 000.
23Журнал VestaHome: строка «камеры: N в 150 км из M».Записать N и M; N не упирается в 6000.

8. Wi-Fi (Mi Note 13 Pro) и OBD

№ДействиеЧто должно бытьЗаметки
24Настройки → Wi-Fi: открыть экран и подождать.Список и состояние обновляются раз в секунду сами.
25В VestaHome «Забыть» MiNote13Pro; подключиться к ней штатным менеджером Wi-Fi WinCE (если доступен).Записать: держится ли связь, есть ли адрес, через сколько секунд обрыв. Тот же обрыв через 4–5 с — дело не в VestaHome.
26OBD: на телефоне выключить Bluetooth; ГУ после перезагрузки; «Настройки → Bluetooth → OBD-адаптер (проверка)» → «Подключить».Подключается; если нет — записать код ошибки с экрана, время.

  • Если Навител не нашёл порт — его Userdata\settings.005.ini.
