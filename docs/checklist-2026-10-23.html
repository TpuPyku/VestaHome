Проверки на ГУ — одиннадцатый лист

Составлено 2026-10-23 по сделанному после десятого листа (дизайн 0.6, 32-битное рисование, анимация панели, тема и заставка). Десятый лист остаётся в силе. ☐ — «сделано», «Заметки» — что увидели. Нужны SD-карта с музыкой, видео и фото, Bluetooth-телефон с музыкой. Журналы — «Диагностика → Журналы» включены.

1. Установка и первый запуск (VestaHomeInstall из Tests\SDMemory\VestaHomeInstall)

№ДействиеЧто должно бытьЗаметки
1Установщик: «VestaHome + загрузчик» → «УСТАНОВИТЬ / ОБНОВИТЬ».VestaHome обновлён; «О системе»: версия 0.6.261023.
2Открыть журнал VestaLogs\VestaHome.log.Есть строка «экран: 800 x 480, N бит на точку» — записать N.
3Приложения → Диспетчер задач → «Память», 5 минут листать экраны.Память VestaHome не растёт без конца (записать сколько); ГУ не тормозит.

2. Внешний вид 0.6

№ДействиеЧто должно бытьЗаметки
4Пройти все разделы нижней панели.Шрифт Golos (не Tahoma), значки Lucide, заголовки строчными («Медиа · Музыка»).
5Сравнить с макетом vesta-home-v0.6.pdf.Карточки не зеленят и не темнее макета; фон — ромбы, книзу темнее, без ряби; справа сверху мягкое оранжевое свечение.
6Выделенные вкладки, строки, плитки настроек.Мягкий оранжевый полупрозрачный — мозаика видна сквозь него; нажатое — сплошной оранжевый.
7Ночная тема (кнопка луны на панели).Всё на треть темнее, ничего не пропадает.

3. Нижняя панель

№ДействиеЧто должно бытьЗаметки
8Главная → Радио → Настройки → Главная.Значки на своих местах; «таблетка» сжимается в круг, круг едет, раскрывается с подписью. Главная → Настройки ≈ 1 с.
9То же быстро несколько раз подряд.Анимация плавная, без рывков и «хвостов»; панель не застревает в середине.

4. Главная

№ДействиеЧто должно бытьЗаметки
10Включить радио FM (источник — радио).Большой «Сейчас играет · Радио»: название, «103,7 МГц · FM1», RDS; ⏮ ⏭ — соседние пресеты.
11Музыка с телефона по Bluetooth.«Сейчас играет · Bluetooth»: трек, полоса, ⏮ ⏯ ⏭ управляют телефоном.
12Интернет-радио и своя музыка по очереди.Виджет показывает то, что звучит; ⏯ работает.
13«Общие → Виджеты главной»: включить «Сейчас играет · компактный».Появляется одной строкой (1×2), показывает то же, что большой.
14Виджет «Поездка» после поездки.Пробег, в движении, средняя, максимальная крупно; расход и запас хода (с OBD).

5. Радио

№ДействиеЧто должно бытьЗаметки
15Экран «Радио».Частота крупно, «МГц · FM1» оранжевым; PTY и «Станции» справа; стрелки ⏮ ⏭ по краям шкалы.
16Тап по стрелке и по краю шкалы (слева, справа).Поиск станции вниз / вверх.
17Тап по «FM1»; свайп по пресетам.Страница меняется FM1 → FM2 → FM3 → УКВ → СВ; точки под пресетами.
18Удержать пустой пресет.Сохранено в пресет N.

6. Медиа, файлы, фото

№ДействиеЧто должно бытьЗаметки
19Вкладки медиа.Нет кнопок «плей» и шестерёнки; у музыки и интернет-радио — кнопка списка, у Bluetooth — телефон.
20Список музыки: зайти в папку, «‹», тап по пути.Строка «‹ SD-карта › Музыка › …»; «‹» — уровень выше; тап по пути — носители (SD-карта, USB-диск, Встроенная карта).
21Папка с сотней файлов — листать.Вторая строка «MP3 · 8,5 МБ»; листание не медленнее прежнего (записать); точек страниц не больше 5.
22Видео: список, выбрать файл.Тот же вид строк; файл играет.
23Фото: папка, открыть снимок на весь экран.Миниатюры без рамок; последнее открытое — оранжевая обводка; на весь экран — плавные переходы цвета (32 бита), без полос.

7. Тема и заставка

№ДействиеЧто должно бытьЗаметки
24«Настройки → Общие → Тема»: выбрать Дайвинг, затем Криптон, затем Марс.Акцент меняется сразу везде (панель, кнопки, обложки, свечение); после перезагрузки сохраняется.
25«Фон заставки» — Мозаика; «Экран → Заставка» 1 мин, подождать.Мозаика; пятно над часами — цвет акцента.
26«Своя картинка» → выбрать фото с SD (большое, с телефона).Фото на весь экран, повёрнуто правильно, без цветного пятна; часы читаются.
27«Своя картинка» → Skin\saver2.png.Заставка с фарами.

  • \SDMemory\VestaLogs\: VestaHome.log (строка «экран: … бит на точку»), SPIPower.log, BTProxy.log.
  • Фото экрана рядом с макетом (п. 5), если цвета отличаются.
