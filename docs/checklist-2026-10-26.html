Проверки на ГУ — четырнадцатый лист

Составлено 2026-10-26. Главное — VestaHome вместо штатной оболочки без перезагрузок (заглушка теперь сама запускает и кормит сторож HzWD.exe). Листы 9–13 закрыты: их открытые пункты — в PLAN.md, раздел 5. ☐ — «сделано», «Заметки» — что увидели. Журналы включены, SD-карта вставлена.

1. Установка и загрузка без оболочки (Tests\SDMemory\VestaHomeInstall)

№ДействиеЧто должно бытьЗаметки
1Установщик: VestaHome (и proxy, как было) → «Установить», перезагрузка с SD.Задание с загрузчиком; после двух перезагрузок — VestaHome.
2Работать 10 минут: радио, музыка, переходы по экранам.ГУ НЕ перезагружается (раньше — на ~40-й секунде). В VestaStub.log: «сторож: HzWD.exe запущен…»; в Диспетчере задач есть HzWD.exe, нет G3NavHMI_orig.exe.
3Выключить зажигание, дождаться сна, включить; затем перезагрузка удержанием крутилки.Оба раза — VestaHome, без сброса через минуту.
4Закрыть VestaHome (если есть выход) или дождаться перехода на штатную оболочку.Штатная оболочка поднимается, ГУ не перезагружается.

2. Без штатной оболочки — то, чему она мешала

№ДействиеЧто должно бытьЗаметки
5Задний ход: с VestaHome на экране и с открытым OSMapsCE.Своя камера с разметкой поверх всего; после — экран, где были.
6«Автомобиль → Камера — Показать», нажать на экран.Закрывается касанием (без оболочки касание доходит).
7Музыка / радио, задний ход, выключить.Звук вернулся, эквалайзер и громкость на месте.
8Кнопки руля (громкость, следующий, телефон) и крутилка; долгое нажатие крутилки.Работают; долгое — окно перезагрузки с «Отмена».
9Выключить/включить зажигание при громкости 20.Громкость при включении — как задано (Звук → «Макс. при включении»).
10Включить фары / дождаться заката.Тема и подсветка переходят в ночь.
11Wi-Fi: подключиться к знакомой точке (старый Redmi) только через VestaHome.Пароль спрашивается один раз (не в менеджере оболочки), адрес получен.
12Телефон по Bluetooth: звонок входящий и исходящий, музыка с телефона.Окно звонка, звук звонка, радио приглушено; музыка играет.
13Выключить ГУ на музыке с SD, включить.Запуск «как в прошлый раз»: тот же источник и экран.

3. Порт для навигаторов (диагностика)

№ДействиеЧто должно бытьЗаметки
14«Настройки → Автомобиль → Порт для навигаторов»: COM6, включить.Переключатель сразу «вкл.», подпись «загружается…», затем «работает» или выключится сам. Записать подпись.
15Прислать журналы.В VestaHome.log строка «порт NMEA: проба DLL здесь …»; есть ли файл VestaLogs\VestaNMEA.log.

4. Остатки прошлого листа

№ДействиеЧто должно бытьЗаметки
16Фото: открыть снимок, вернуться к миниатюрам.Углы миниатюр скруглены, оранжевая рамка вокруг последнего — ровная, фото не вылезает.
17Радио → Список → «Автопоиск», затем «В пресеты» два раза.«Пишу N из M», в конце «записано N из M»; пресеты FM1–FM3 — найденные станции.
