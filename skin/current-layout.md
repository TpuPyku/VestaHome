# current-layout.md — текущая раскладка скина G3NavHMI

Справочник координат кнопок/виджетов штатной оболочки. Основа для патчинга
(Вариант 1) и для `vesta-skin02`.

Источники:
- `MAIN/PNG-list.txt` — полный список файлов скина (по экранам);
- `MAIN/VestaMMCskin.ai` — артборды-экраны (отрендерены в `_ai/screens/` парсером `parse_skin.py`);
- Ghidra (`Vesta/G3patch/ghidra`) — константы координат в коде;
- `MAIN/Foto/display_*.bmp` — точные скриншоты 800×480.

## Пробелы
- Не определены 8 из 12 экранов (см. таблицу) — сверить по рендерам.
- Точные координаты Плеера/Телефона/Настроек/Видео/Фото/AUX/Инфо — нужен разбор
  конструкторов в Ghidra (перегенерировать `layout.tsv`/`ids.tsv`) или замер по
  рендерам.
