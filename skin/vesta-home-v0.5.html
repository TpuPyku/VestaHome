VestaHome 0.5 — своя оболочка

Раскладка 800×480 без привязки к сетке G3NavHMI. Снимки — ПК-сборка VestaHomePC.exe (2026-10-12); значения на экранах — демо.

Правила раскладки

  • Верхний бар на всех экранах (0–56): «назад», если есть куда вернуться; заголовок; результат последнего действия; метки GPS, Bluetooth, USB; температура снаружи; часы (касание — громкость).
  • Нижний бар — только на основных экранах (408–480): Главная, Радио, Медиа, Телефон, Приложения, Настройки + день/ночь. Текущий раздел оранжевый. Раздел открывается с чистой историей; «Медиа» — последний источник.
  • Контент основных экранов — 64…400. Вложенные экраны (список станций, PTY, плеер видео, просмотр фото, контакты, журнал, звонок, ярлык, клавиатура, выбор файла, автомобиль) не меняют раскладку и оставляют свою нижнюю панель.
  • Главная — набор виджетов: две страницы по пять, сетка 3×2 с ячейками 248×158, первый виджет страницы на две ячейки. Нажатие на виджет открывает его экран, маленькие кнопки внутри работают сами.
  • «Приложения» — функции VestaLaunch внутри VestaHome: apps.txt рядом с exe, правка ярлыков, свои иконки, запуск поверх оболочки и «сторож» окон. VestaLaunch остаётся отдельной программой для штатной оболочки.
